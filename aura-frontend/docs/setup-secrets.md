# Configurar Secrets de Supabase

## Meta / Facebook
Ejecutar en la terminal (dentro del proyecto):
```bash
supabase secrets set META_APP_SECRET=tu_meta_app_secret
```

## X / Twitter (cuando tengas las credenciales)
```bash
supabase secrets set X_CLIENT_SECRET=tu_client_secret
```

## Verificar secrets
```bash
supabase secrets list
```
