# Tasks: admin-dashboard-metrics

> Dashboard real de admin con las 4 métricas pedidas (clientes, costo estimado Google AI, publicaciones, imágenes incluyendo rehechas). Este change crea el **sustrato de datos** (tabla de eventos + precios + RPC agregador), el **dashboard** que lo consume (ruta `/admin`, OQ1 resuelto 2026-08-18 — originalmente planeada como `/admin/dashboard`, ver design.md D6), y el **contrato de evento** para que el workflow n8n empiece a loguear (design D1-D14).
>

>
> **Regla de oro 2 — no tocar `codigo.json`:** la instrumentación de n8n es el change hermano `n8n-usage-events-logging` (design D8). Acá solo se **documenta** el contrato.
>
> **Regla de oro 3 — no regresionar:** `link-code-reproducible`, `secrets-migration`, `error-handling`, `redis-expiration`, `pdf-virus-scan`, `input-security-hardening` no se tocan; sus tests de verificación deben seguir pasando. Ninguna dependencia nueva en `package.json` (design D11).
