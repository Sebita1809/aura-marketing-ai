# Tasks: publish-video-platform-schedule

> **Cómo se implementa este change:** el workflow vive en n8n; `codigo.json` (raíz, 120 nodos) es el export y la fuente de verdad versionada. Para cada grupo: editar `codigo.json` con cuidado → importar en la UI de n8n → probar por Telegram → re-exportar → **sanitizar secretos según `docs/secret-sanitization-procedure.md` antes de commitear** (el repo es público). No dejar el export desincronizado entre grupos.
>
> **Orden de implementación** (ver `design.md`, Migration Plan): marca de agua → programación → selección de plataformas → contenido existente (primero imagen subida, después video). Cada bloque es probable de forma independiente.
>
> ⚠️ **Recordatorio de regresión conocida:** `onError: "continueErrorOutput"` va como propiedad **del nodo** (hermana de `parameters`), NUNCA dentro de `parameters`.
>
> 🚫 **Regla de negocio dura (D12):** la marca de agua "generada con IA" se aplica **solo** a las imágenes de `Generate an image` / `Edit an image`. **Nunca** al contenido que sube el usuario (imagen o video propios).
